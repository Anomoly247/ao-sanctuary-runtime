## Strong canonical signals

### 1. AO Alive is an active world, not a static dashboard

`ReactArtifact.html` reinforces the strongest current product direction:

- identity is an earned current;
- the Sanctuary is a persistent homeworld;
- positive play and contribution create movement;
- Glow Points and Anom Coins have different roles;
- mounts are identity, emotion, and transit anchors;
- color is operational language, not decoration;
- the universe should feel alive through staggered breathing, orbiting, and portal motion.

This is compatible with the current Sanctuary direction and should inform the Moonberry Farm activity.

### 2. Off-Grid / Moonberry Farm belongs inside Sanctuary

The attached `offgrid.html` is primarily a Google Docs export shell and does not contain a reliable machine-readable content body. The user-provided Moonberry Farm specification is therefore the authoritative source for this route:

- Off-Grid Sanctuary;
- Moonberry Farm;
- House 1;
- gratitude as the harvest mechanic;
- calm planting, watering, and harvesting;
- mount-assisted care;
- private Growth Notes;
- private Glow nourishment without public behavior scoring.

Implementation recommendation: add this as a child-safe Sanctuary world route, not as a new disconnected product or a public leaderboard surface.

### 3. The master index is useful operationally, not as live analytics

`AOUniverse—MasterIndex.html` provides a practical status-card pattern: live, pending, needs-link, and urgent. Its hardcoded counts and infrastructure statements must not be copied into product UI as live facts. The pattern is appropriate for an owner-only control surface if each status is derived from a real registry or deployment check.

Useful reusable ideas:

- filterable destination registry;
- status chips with text plus non-color indicators;
- explicit “needs link” placeholders;
- canonical domain and repository mapping;
- smooth navigation and visible focus states.

### 4. The Help Hub is a visual reference, not a direct Sanctuary theme

`pasted_file_jhAVCw_AnomInternetHelpHub.html` demonstrates:

- skip navigation;
- responsive support panels;
- support-terminal language;
- unaltered identity imagery;

- readable 44px-class controls.

It still uses hot pink and violet as primary colors. Those tokens should not be imported into Sanctuary’s active visual system. Preserve the information architecture and accessibility patterns, then translate the visual layer to AO gold/cyan with rare signal accents only.

### 5. KDP and story artifacts are content surfaces

`Kdp-Preview-Grid.html`, `Master-Anom-Hub-Games.html`, `Alive-Landing-Final-Real.html`, and `Master-Anom-Black-Gold.html` provide content-card, game-hub, identity, and black/gold presentation patterns. They should be treated as source material for routes and content registries, not pasted wholesale into the React runtime. Generated HTML contains bundled styles, stale labels, and in some cases legacy color tokens.

## Conflicts to resolve before migration

| Area | Conflict | Recommended treatment |
|---|---|---|
| Color | New masters use `#ff00c8`, violet, pink, and magenta heavily. | Keep black/gold/cyan as Sanctuary primary; reserve rare signal colors for celebrations or portal energy. |
| Counts | Master Index includes fixed live/pending/urgent totals. | Use only in owner tooling when derived from an authoritative registry. |
| Domains | Older artifacts contain historical route/domain assumptions. | Use current canonical domain map from `AOUniverseSourceBrief.md`; do not copy stale links blindly. |
| Content authority | Some HTML is a generated artifact or Google Docs shell. | Treat authored source brief and explicit user canon as higher authority than rendered export text. |
| Economy | Some artifacts imply mounts and coins are immediately purchasable. | Preserve earned-first, age-aware, reviewable progression; do not add real-money currency flows from these references alone. |
| Child safety | Some game/movie interfaces expose broad navigation and social surfaces. | Gate external links, chat, uploads, and sharing by age tier and guardian state. |
