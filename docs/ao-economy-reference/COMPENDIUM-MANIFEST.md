# AO Universe Complete Lore Compendium Manifest

The original ZIP is preserved outside the WebDev source checkpoint because it contains a large bundle of generated images:

- `/home/ubuntu/ao-universe-complete-lore-compendium.zip`
- Extracted working copy: `/home/ubuntu/ao-universe-complete-lore-compendium/`

The project checkpoint contains the canonical text sources under `compendium/` so they remain searchable and reviewable without committing the full generated-artifact bundle. The extracted bundle includes the generated mount/collector artwork and the District B Arcade PDF.

The current project decision remains **separate deployments connected by an AO bridge**, even though the historical AO-GAMES-SPEC describes a one-repo prototype. That prototype is preserved as source context, not treated as an instruction to consolidate the live sites.
